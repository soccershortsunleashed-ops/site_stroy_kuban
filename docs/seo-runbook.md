# SEO Runbook: StroyTrest-23

## 1) Подтверждение в поисковиках

Добавьте токены в `web/.env`:

- `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`
- `NEXT_PUBLIC_YANDEX_VERIFICATION`
- `NEXT_PUBLIC_MAILRU_VERIFICATION` (опционально)

Шаблон: `web/.env.seo.example`.

После добавления токенов:
1. Пересобрать и задеплоить сайт.
2. Проверить наличие meta verification тегов в HTML главной страницы.

## 2) Регистрация и индексирование

### Google Search Console
1. Добавить ресурс `https://stroytrest-23.ru`.
2. Подтвердить владение через meta tag.
3. Отправить sitemap: `https://stroytrest-23.ru/sitemap.xml`.
4. Проверить Indexing -> Pages (исключенные/ошибки).
5. Для ключевых URL выполнить `Request Indexing`:
- `/`
- `/about`
- `/projects`
- `/services`
- 4 страницы `/projects/[slug]`

### Яндекс.Вебмастер
1. Добавить сайт `https://stroytrest-23.ru`.
2. Подтвердить владение через meta tag.
3. Добавить sitemap: `https://stroytrest-23.ru/sitemap.xml`.
4. Проверить Диагностика -> Индексирование -> Обход.
5. Запустить переобход ключевых страниц.

## 5) Технический контроль (ежемесячно)

1. Проверка `robots.txt` и `sitemap.xml` доступности.
2. Lighthouse mobile/desktop по `/` и `/projects`.
3. Проверка битых ссылок (404).
4. Проверка Core Web Vitals в GSC.
5. Проверка изменения сниппетов (title/description) в выдаче.

## 6) Уже внедрено в проекте

- `robots.txt` генерируется через `web/app/robots.ts`
- `sitemap.xml` генерируется через `web/app/sitemap.ts`
- `Organization` + `LocalBusiness` JSON-LD в `web/app/layout.tsx`
- Базовые OpenGraph/Twitter/robots/canonical в `web/app/layout.tsx`
